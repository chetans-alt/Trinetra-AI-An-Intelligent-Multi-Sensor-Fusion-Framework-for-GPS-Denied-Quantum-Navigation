# S0 Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the docs-only repository into a working Python 3.12 package. It must have a lockfile, lint, type checks and tests; a test that enforces the hexagonal import rule; a verified MagNav download script; and the three founding ADRs.

**Architecture:** The package uses a src layout (`src/trinetra/`) managed by uv. In S0 `core/` is still empty, but the import-rule test already guards it. Data fetching lives in `trinetra.adapters.fetch`, built from pure, testable functions with injectable I/O, and `scripts/download_data.py` is a thin wrapper around it. Raw data never enters git. Only a SHA-256 manifest is committed.

**Tech Stack:** Python 3.12, uv 0.13, numpy, scipy, pytest, hypothesis, ruff, pyright, and the stdlib (`urllib`, `hashlib`, `json`, `argparse`, `ast`).

**Spec:** [docs/superpowers/specs/2026-11-14-trinetra-project-plan-design.md](../specs/2026-11-14-trinetra-project-plan-design.md) (sections 3, 5, 6 S0 and 10)

## Global Constraints

- Python **3.12**, managed by **uv**, with `uv.lock` committed.
- `src/trinetra/core/` must never import `torch`, `h5py`, `rclpy`, `pandas`, any `trinetra.adapters` / `trinetra.compensation` module, or a dataset name (`magnav`, `ronin`).
- **Never commit** raw data, derived Parquet, map tiles or trained weights. `data/` and `runs/` are gitignored.
- MagNav source: **Zenodo record 12723700**. Downloads must be verified against Zenodo's per-file MD5, and the committed manifest is `datasets/manifest.json` (SHA-256).
- Unit tests never touch the network or real data.
- Infrastructure comes only from the spec's "Day 1" row. Do not add CI, MLflow, DVC, Docker or Hydra in S0.
- Commits follow Conventional Commits and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- The repository path contains spaces. Quote it in every shell command.

## Review Focus

1. **A download is interrupted midway.** A partial file must never be treated as valid. Write to `<name>.part`, verify, then rename. Pinned in Task 3 by `test_partial_download_not_promoted`.
2. **Checksum mismatch.** Raise `ChecksumError` naming the file, leave no file at the final path, and exit non-zero. Pinned by `test_md5_mismatch_raises_and_leaves_no_file`.
3. **Re-running with files already present.** Skip files whose size and MD5 already verify, rather than re-downloading about 1.2 GB. Pinned by `test_existing_verified_file_is_skipped`.
4. **The Zenodo record changes after the manifest is committed.** Fail loudly with `ManifestMismatchError` and never overwrite the manifest silently. Pinned by `test_manifest_mismatch_raises`.
5. **Import forms that evade a naive import check:** `from torch import nn`, `import torch.nn as tnn`, and `from trinetra.adapters import fetch`. Pinned in Task 2 by `test_checker_flags_all_import_forms`.

### Task 3: Verified MagNav download

**Files:**
- Create: `src/trinetra/adapters/__init__.py`, `src/trinetra/adapters/fetch.py`, `scripts/download_data.py`, `tests/adapters/__init__.py`, `tests/adapters/test_fetch.py`, `tests/adapters/fixtures/zenodo_record.json`, `datasets/README.md`, `docs/adr/0003-data-and-licence-policy.md`

**Interfaces:**
- Consumes: the package from Task 1.
- Produces (in `trinetra.adapters.fetch`):
  - `ZENODO_RECORD_ID: Final = 12723700`
  - `@dataclass(frozen=True) RemoteFile(key: str, url: str, size: int, md5: str)`
  - `parse_zenodo_record(record: dict) -> list[RemoteFile]`. Reads `record["files"][i]`: `key`, `size`, `checksum` (`"md5:<hex>"`) and `links["self"]`.
  - `select_files(files: list[RemoteFile], include: str) -> list[RemoteFile]`. Uses an `fnmatch` glob on `key`.
  - `md5_of(path: Path) -> str` and `sha256_of(path: Path) -> str`. Both stream in 1 MiB chunks.
  - `download_file(f: RemoteFile, dest_dir: Path, open_url: Callable[[str], BinaryIO] = urllib.request.urlopen) -> Path`
    1. Return early if `dest_dir/f.key` already exists with the right size and MD5.
    2. Otherwise stream to `f.key + ".part"`, verify, then `Path.replace` to the final name.
    3. On mismatch, delete the `.part` and raise `ChecksumError(f.key)`.
  - `build_manifest(paths: dict[str, Path], files: list[RemoteFile]) -> dict`, returning `{"source": "zenodo:12723700", "files": {key: {"size", "md5", "sha256"}}}`.
  - `check_manifest(manifest: dict, files: list[RemoteFile]) -> None`. Raises `ManifestMismatchError` if any key present in both has a different `size` or `md5`.
  - Exceptions: `ChecksumError`, `ManifestMismatchError`, both subclasses of `FetchError(Exception)`.

The fixture `zenodo_record.json` is a hand-written two-file record in that shape. Use keys `Flt1003.h5` and `README.txt`, and give each an MD5 computed from known bytes in the test. Tests inject `open_url` with a function that returns `io.BytesIO(payload)`, or one that raises midway.

- [ ] **Step 1: Write the failing tests** in `tests/adapters/test_fetch.py`
  - `test_parse_zenodo_record`: 2 `RemoteFile`s, with `md5` stripped of the `md5:` prefix.
  - `test_select_files_glob`: `"*.h5"` returns only `Flt1003.h5`.
  - `test_download_verifies_and_writes` (`tmp_path`): the final file exists, its bytes equal the payload, and no `.part` remains.
  - `test_md5_mismatch_raises_and_leaves_no_file`: `ChecksumError` is raised; neither the final file nor the `.part` exists.
  - `test_partial_download_not_promoted`: `open_url` returns a stream that raises `OSError` after 10 bytes. The `OSError` propagates and no final-name file exists.
  - `test_existing_verified_file_is_skipped`: pre-write the correct bytes. An `open_url` that would raise is never called.
  - `test_manifest_round_trip`: `build_manifest` then `check_manifest` passes. The `sha256` field equals `hashlib.sha256(payload).hexdigest()`.
  - `test_manifest_mismatch_raises`: change one MD5 in the files list, and `check_manifest` raises `ManifestMismatchError`.

- [ ] **Step 5: Write `scripts/download_data.py`**

This is an `argparse` wrapper that adds no logic of its own.

Options:
- `--list`: print key, size and MD5 for every file in the record, then exit.
- `--include GLOB`: default `DEFAULT_INCLUDE = "*.h5"`. Narrow it in Task 5 once the real key names are seen.
- `--dest`: default `data/raw/magnav`.

Flow:
1. Fetch `https://zenodo.org/api/records/12723700` as JSON.
2. If the manifest exists, run `check_manifest` before downloading.
3. Download each selected file.
4. Exit codes: 0 on success; 1 on `FetchError`, after printing the message; 2 on network errors, after printing "Could not reach Zenodo: …".
